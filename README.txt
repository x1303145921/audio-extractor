==============================================
 音频提取器 audio-extractor · 便携版
==============================================

【使用方法】
  1. 双击「启动工具-最小化.bat」——服务在任务栏最小化窗口后台运行，浏览器自动打开
     （或双击「启动音频提取工具.bat」，带控制台窗口的经典方式）
  2. 首次运行如遇 SmartScreen 蓝色提示：点「更多信息」→「仍要运行」
  3. 浏览器自动打开 http://127.0.0.1:8912 （端口被占用会自动顺延）
  4. 拖入视频文件 → 选择输出格式 → 开始提取 → 点击下载
  5. 用完在页面底部点「退出服务」即可关闭后台服务

【手机访问（可选）】
  服务默认监听所有网卡：手机与电脑连同一 WiFi，在电脑上用
  启动窗口打印的局域网地址（如 http://192.168.x.x:8912）访问。
  手机打不开时，请在 Windows 防火墙中允许 Node.js 通过（专用网络）。

【常见问题】
  Q: 提示「不是内部或外部命令」或一闪而过？
  A: 请确认 node.exe 和 ffmpeg.exe 与本文件在同一目录。
  Q: 浏览器没自动打开？
  A: 手动访问窗口中显示的地址即可。
  Q: 端口被占用？
  A: 服务会自动从 8912 往后找空闲端口，以窗口显示为准。

【系统要求】 Windows 10 / 11（64 位），无需安装任何依赖，无需管理员权限。
