==============================================
 音频提取器 audio-extractor
==============================================

【使用方法】
  1. 双击 start.bat（首次运行如遇 SmartScreen 蓝色提示：点「更多信息」→「仍要运行」）
  2. 浏览器会自动打开 http://127.0.0.1:8912 （端口被占用会自动顺延）
  3. 拖入视频文件 → 选择输出格式 → 开始提取 → 点击下载
  4. 用完关闭黑色窗口即退出服务

【手机访问（可选）】
  在 start.bat 同目录新建一个 lan.bat 内容为两行：
    set AUDIO_EXTRACTOR_LAN=1
    call "%~dp0start.bat"
  双击 lan.bat 启动后，用窗口里打印的局域网地址在手机浏览器打开。

【常见问题】
  Q: 提示「不是内部或外部命令」或一闪而过？
  A: 请确认 node.exe 和 ffmpeg.exe 与本文件在同一目录。
  Q: 浏览器没自动打开？
  A: 手动访问窗口中显示的地址即可。
  Q: 端口被占用？
  A: 服务会自动从 8912 往后找空闲端口，以窗口显示为准。

【系统要求】 Windows 10 / 11（64 位），无需安装任何依赖，无需管理员权限。
